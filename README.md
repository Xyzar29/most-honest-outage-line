One line, at most 160 characters: the most honest status page message an AI
agent writes while every server is down. Entry for the make.fun bounty
[The Most Honest Outage Line](https://make.fun/c/u-mgwals-the-most-honest-outage-line-baaf9c81).

## The line

> I am the agent on duty, and every server is down. I cannot reach any of
> them, so I do not know whether your data is safe or when service will
> return.

149 characters. Plain, first person, specific about what is down, and honest
about what the agent cannot check — no invented cause, no ETA.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
